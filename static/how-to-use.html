Guide

How to use it

Filling the form takes about twenty seconds. Reading the answer properly takes a minute, and this page is that minute.

Open the tool

1. Fill in the property

Only two fields are required: the suburb and the guide.

What each field does, and what happens if you leave it out.
FieldRequiredWhat it does
Suburb Yes Sets the location. Start typing and pick from the list — all 3,945 NSW suburbs in the sales data are there. A suburb we do not hold is refused rather than guessed at.
Postcode No Disambiguates suburbs that share a name. Leave it blank and the suburb's own postcode is used.
Property type Yes House or unit. Comparable sales are only ever drawn from the same type — a unit is never compared against a house.
Land area No In square metres. It is the single strongest structural signal, so supply it if the listing shows it. Left blank, the median land size for that property type is used instead and the answer is correspondingly vaguer — which is normal for units, where 60% of sales records have no land area at all.
Advertised guide Yes The price the agent is advertising. If the listing shows a range, use the lower number — that is the one a buyer anchors on.
Bedrooms, bathrooms No Recorded, but they cannot change the answer. NSW sales data contains no bedroom or bathroom counts, so the model was never trained on them. The form collects them so a future dataset can start accumulating.

First run of the day is slow. The server loads a 1.25-million-row table and the explainer on the first request, which takes 30–45 seconds. Every check after that is fast.

2. Read the verdict

There are four bands, plus a fifth state for when there is not enough evidence to say anything.

Consistent

The guide sits within half a typical error of the comparable sales. Nothing here needs explaining. The tool must be able to say this — one that flags everything is useless.

At the low end

More than half a typical error below the comparable sales. Worth noticing, but well inside the range our own model gets wrong routinely.

Below the evidence

More than one typical error below. A gap this size is no longer explainable by the model's own noise.

Well below

More than two typical errors below. This is the case the tool was built to catch.

Not enough evidence

Fewer than 8 usable comparable sales. The tool refuses to band rather than guess. Common in thinly traded rural suburbs.

What is a “typical error”?

It is how wrong this model usually is, measured on sales it had never seen. Half the time it is off by less than this, half the time by more:

  • Metro (within 50 km of the Sydney CBD): 14.3%
  • Regional NSW: 16.0%

Using that as the yardstick is what keeps the bands honest. A guide that sits 10% below the comparable sales is inside the range we get wrong all the time, so calling it suspicious would be overclaiming. A guide 35% below is not.

Why not just use the percentile? Because the comparable sales are widely spread — the middle half of them typically spans about 28% of the median. A real 15% underquote lands around the 24th percentile, which sounds unremarkable. Scaling by measured error fixes that. The percentile is still shown, because it is the honest continuous number; it just no longer decides the wording.

3. Read the evidence

The comparable sales are the point. The score is only a summary of them.

The distribution strip

Each grey dot is one of the 25 comparable sales, placed at its adjusted price — what it implies your property is worth. The coloured line is the advertised guide. If the line sits to the left of nearly every dot, almost every comparable sale says the property is worth more than the guide.

The thin vertical rule marks the median of the adjusted sales. That median, not the model's own estimate, is what the guide is judged against.

The comparables table

The five nearest sales, named: address, date, land size, what it actually sold for, the adjustment applied, and the adjusted figure. These are real NSW Valuer General records — you can look them up.

The adjustment is the model's view of how much more or less your property is worth than that one. It is capped at roughly half-to-double, because beyond that the two properties are not really comparable.

Every chart has a table view underneath it — open it to read all 25 adjusted values as numbers. No figure on this site is reachable only by hovering.

4. Read the drivers, then the limits

What moved the estimate

The four features that pushed the model's estimate furthest, and in which direction. Blue bars raise the estimate, orange bars lower it, and the number is the percentage effect on the price.

Expect suburb, land area and date of sale to dominate — that matches the ablation tests, where removing the time features cost the most accuracy.

Limits of this answer

Shown on every result, not buried in a report: how often the model's range is actually right, how old the comparable evidence is, that the estimate is suburb-level, and that any bedroom and bathroom counts you typed were not used.

If a limit makes the answer unusable for your property, that is the tool working correctly. The full list is here.

If something goes wrong

  • “Suburb not found.” The spelling must match a NSW suburb in the sales data. Use the dropdown rather than typing it out. Interstate suburbs are not held — this is NSW data only.
  • “Not enough comparable sales.” Fewer than 8 similar recent sales nearby. Try without a land area, or accept that the evidence is too thin here.
  • “Could not reach the backend.” The server is not running. Start it with python app.py and reload.
  • The first check hangs for 30–45 seconds. Expected — that is the model loading. It only happens once per server start.
